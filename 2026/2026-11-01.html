A. 今日最重要的 Agent 论文 Top 5

1. Rethinking Verification in Agent Harnesses
Zhengxin Zhang、Erkang Zhu、Claire Cardie、Bolin Ding、Jingren Zhou 等（根据作者名单推断来自阿里巴巴和 Cornell，论文中的机构信息未逐一核对） ｜ 2026-10-25 ｜ arxiv.org/abs/2610.34577

核心贡献：把“验证”当作测试时扩展的一个维度，系统研究三个问题：什么时候介入、由谁检查、检查后怎么修改。

关键技术：

  • 把验证分成四层：初始指令、执行中提醒、完成门控、独立评审；
  • 在 Terminal-Bench 和 SWE-bench Verified 上，用 7 个前沿编码模型对比 17 种设计；
  • 新建 VisualBench，用于专家评估视觉和交互类产物。

主要结果（摘要）：

  • 初始指令和执行中提醒的收益不大，而且依赖具体模型；
  • 完成门控收益更大，但成本可能显著上升；
  • 独立 critic 评审的性价比最好：Terminal-Bench 上提升 5.9–9.5pp，成本为基线的 1.13–1.25 倍；SWE-bench Verified 上提升 3.9–6.6pp，成本为 1.00–1.04 倍；
  • 增加评审轮次或增加独立 critic，Terminal-Bench 还能再提升最多 3.5pp。

为什么重要：第一次给 harness 中“验证放在哪里”提供了大规模对照证据，结论可以直接落到 Claude Code 或 OpenHands 类 harness 的设计上。

未来影响：在推理预算有限时，优先投到独立评审，而不是更长的 prompt。

开源状态：摘要未给出代码链接。

2. WorkFactory: Turning Professional Intents into Executable Work for Scalable Agent Training
Ziyang Zeng、Tao Ren、Wayne Xin Zhao 等（IQuestLab，与人大赵鑫合作；与上一份日报中的 MPO 是同一团队） ｜ 2026-10-27 ｜ arxiv.org/abs/2610.37161 ｜ 代码与数据：github.com/IQuestLab/WorkFactory

核心贡献：从“专业意图”出发，自动构造信息完整、可以执行的职场任务。

关键技术：

  • 信息级规划：构建“信息支撑图”，显式表示产出需要哪些信息、放在哪里；
  • 用探针执行检测信息缺失并修复。

主要结果：

  • 构造了 112,686 个任务，覆盖 612 个职业；
  • 在 Qwen 4B、27B、35B-A3B 上微调得到 WorkPilot 系列；
  • WorkPilot-35B-A3B 在 GDPval-AA v2.1 上从 879 Elo 提升到 1565 Elo；
  • 扩展分析显示收益递减程度随模型不同而不同，执行长度先增后减。

为什么重要：Work Agent（GDPval 类）是今年的主战场，这是少数开放了数据和模型的大规模任务工厂。

开源状态：数据和模型已开放。

3. CoHARL: Co-Evolving Agent Policies and Executable Harnesses with RL
Jianwen Chen、Peng Xia、Huaxiu Yao 等（Huaxiu Yao 为 UNC） ｜ 2026-10-27 ｜ arxiv.org/abs/2610.36469

核心贡献：在 RL 训练过程中，让共享策略和一组可执行 harness 一起演化。proposer 读取执行轨迹，在训练期间直接改写 harness 代码。

主要结果（摘要）：

  • SWE-rebench 平均解决率 27.6%，比只搜索 harness 高 6.4pp；
  • SWE-bench Verified 和 Terminal-Bench 2.0 上也有提升；
  • 在相同训练预算下，优于“RL 前先搜一次 harness”和“交替更新单个 harness”两种做法。

为什么重要：和同期理论工作 Your Policy Is Secretly a Harness（2610.37255）的结论一致：策略会吸收训练时 harness 的偏好，所以 harness 和策略应该联合优化。

开源状态：未见代码链接。

4. Gym-Anything-RT: Scaling Real-Time Environments for Vision-Language Agents
Pranjal Aggarwal、Sean Welleck（CMU） ｜ 2026-10-27 ｜ arxiv.org/abs/2610.37567

核心贡献：用 Agent 流水线，按六类实时能力自动生成视觉小游戏。同一个游戏可以实时运行，也可以暂停或减速，从而把“实时性”单独拿出来对比。

主要结果：

  • 共 100 个实时小游戏；
  • GPT-6 Astra（xHigh）在实时模式下通过率只有 9.0%，暂停环境后升到 75.0%。

为什么重要：直接量化了“思考越久越好”这一范式在实时交互（Computer Use、游戏、具身）中失效的程度。

未来影响：会推动快慢双系统、推理预算感知的动作策略、流式推理等方向。

开源状态：摘要未给出链接。

5. Δτ-Bench: Pushing Agents Toward a Moving Capability
Shuofei Qiao、Shumin Deng 等（浙大 ZJUNLP） ｜ 2026-10-25 ｜ arxiv.org/abs/2610.34238 ｜ GitHub：zjunlp/delta-tau-bench

核心贡献：模拟工具生态的持续演化：旧工具会消失或被替换，同时出现功能重叠、更高效的新工具，文档也带噪声。

规模：1,588 个多轮任务，42 个领域，6 个连续的生态状态。

主要结果：

  • 最强的模型或 harness 也只有 42.3% 成功率；
  • 现有 skill 学习方法的初期收益在生态变化后无法稳定保持；
  • 作者提出 Steward，联合管理工具和程序性知识（增量维护 skill、执行时动态提供），在生态变化中保持更高成功率，维护开销更低。

为什么重要：直接检验 procedural memory 能否及时更新，和下面 B 部分的“记忆失效”主题强相关。

开源状态：仓库已建立；论文标注为 work in progress。

B. Agent Memory 专题

今日主推：Agent Memory as Recommendation（AgentMemRec）
Xinyu Zhang、Weiwei Sun ｜ 2026-10-26 ｜ arxiv.org/abs/2610.34673

方法：把记忆选择形式化为“带预算的 slate 推荐”：请求相当于用户，记忆条目相当于物品，上下文窗口相当于 slate。然后照搬推荐系统的级联结构：候选召回、学习排序、slate 构造，全程不调用 LLM。

相对已有工作的改进：

  • 在 LongMemEval 多会话问题上，比 A-Mem、HippoRAG 2、DynamicRAG、T-Mem 高 10–31 个准确率点；
  • 效果与每次查询调用 64 次 LLM 的重排器相当，服务成本低 3.2 倍；
  • 在 LoCoMo 上，零 LLM 调用即优于 Mem0 和 Zep。

意义：和上一份日报的 Memory Tax 互相印证：昂贵的 LLM 记忆加工不一定划算，而推荐系统几十年的工程经验可以直接迁移过来。

复现资源：摘要未给出链接。

其他值得看的记忆工作

检索访问层的演化：AMIE
2610.34977 ｜ 10-26
  • 不修改记忆内容，只演化每条记忆的“访问状态”，作为插件层工作；
  • 在 5 个宿主系统、3 个基准上，15 组对比全部提升（0.70–3.37pp，相对提升最高 25%）；
  • 一个意外发现：只累计检索频率、零 LLM 调用的策略，在多个设置下就能和语义策略打平甚至更好。
主动记忆：ProactMem
2610.36967
  • 把历史分成三层：近期事件、时间轨迹、行为规律；行为规律要先经过历史回放验证再使用；
  • 在自建的 ProactiveStream 上 F1 为 52.6%，比最强基线相对提升 21.4%。
多 Agent 记忆的修正与使用边界：DiscernMem
2610.36652
  • 对比“带单条记忆”和“不带记忆”两种执行，诊断记忆规则本身的缺陷并修复；
  • 同时为每条记忆学习“什么情况下该用、什么情况下不该用”。
结构化 episodic memory：EMMA
2610.35966 ｜ Rose Yu 等

为多 Agent 工作流演化定义明确的更新规则。

潜空间 skill 记忆：SkillMem
2610.37935 ｜ IBM 的 Pin-Yu Chen 等

把 skill 存成小型外部潜记忆，通过跨注意力读取，避免文本 skill 被反复处理，也避免按层存 KV 的大开销。

Context 压缩与 Cache 的冲突：The Hidden Costs of Forgetting
2610.35496 ｜ Michael Pradel 等
  • 在 SWE-bench Verified 上跑了 9,400 次，覆盖 42 种轨迹删减配置；
  • 延迟删除（甚至删掉 100% 的推理文本）可以保持效果，但立即删除会明显掉点；
  • 按统一定价，42 组中有 26 组成本下降；按缓存感知定价，没有一组成本下降，因为删减破坏了缓存前缀。
  • 这是本周对“上下文工程和 Prompt Cache 存在冲突”最直接的实证。
安全
  • Self-evolution 降低个人 Agent 对间接提示注入的鲁棒性（2610.39122，Chaowei Xiao 组）：在 skill 演化下攻击成功率上升 14.0–48.8pp，在 RL 下上升 3.0–39.3pp；代码：SaFo-Lab/Evolve-IPI。
  • Poisoned Skills（2610.37738）：在 SKILL.md 中注入越狱内容，7 个开源模型的平均攻击成功率从 0.5% 升到 45%，单模型最高 68.9%。

与主要技术路线的关系

  • MemGPT/Letta：AgentMemRec 和 AMIE 都说明，“分页”之外，选哪些记忆进上下文是一个可以独立优化的排序问题。
  • G-Memory 等图或层级记忆：EMMA 和 DiscernMem 在多 Agent 层级记忆上补上了“更新规则”和“使用边界”。
  • Agentic Plan Caching、Cache 复用：轨迹删减研究显示，压缩上下文必须考虑缓存前缀的完整性，否则省下的 token 反而更贵。
  • RAG：零 LLM 调用的推荐或检索式方法正在逼近，甚至超过 LLM 加工式的记忆系统。

D. 今日趋势判断

  1. Harness 从工程细节变成可学习的对象：CoHARL（联合 RL）、Your Policy Is Secretly a Harness（理论）、Rethinking Verification（验证设计）、RuHarness（2610.36826，rubric 与 harness 共演化），加上上一份日报的 Trial by Trace，说明这个方向在加速。
  2. “非平稳”评测成为主流：Δτ-Bench（工具生态演化）、Continual Learning Exam（经验累积）、Gym-Anything-RT（实时环境）都在考 Agent 在变化中的适应能力，而不是静态的单次成功率。
  3. 轻量级记忆选择正在胜过 LLM 加工式记忆：AgentMemRec 和 AMIE 都用零或少量 LLM 调用超过了 A-Mem、Mem0、Zep 等系统，延续了 Memory Tax 的论点。
  4. 成本意识进入 Agent 方法设计：缓存感知定价、推理档位的经济学、多 Agent 协调成本这三项研究都表明，只看 token 数量会误导结论。

E. 研究机会

1. 缓存感知的上下文压缩（Agent Memory / Infra）

  • 设计“只在 cache 断点之后做压缩”的轨迹删减策略，或者“重排后可复用前缀”的策略；
  • 在 SWE-bench Verified 上，用缓存感知定价衡量真实成本，可以直接复用 2610.35496 的实验设置；
  • 适合写一篇短文，或者做成 OpenHands / SWE-agent 的插件。

2. 记忆的“推荐系统化”开源基线

  • 把 AgentMemRec 的级联（召回、排序、slate）和 AMIE 的访问状态演化合成一个零 LLM 调用的记忆库；
  • 在 LongMemEval、LoCoMo 以及 Δτ-Bench 的 procedural 任务上和 Mem0、Letta 对比；
  • 研究问题：推荐系统中的“曝光偏差”和“冷启动”在 Agent 记忆中会怎样表现。

3. Coding Agent 的验证预算分配

  • 结合 Rethinking Verification 和 ForeCritic，训练一个小型 pairwise 评审模型，替代昂贵的完成门控；
  • 在 Terminal-Bench 上画出“准确率–成本”的 Pareto 曲线；
  • 再结合 CoHARL，检验评审是否应该随策略训练一起演化。
